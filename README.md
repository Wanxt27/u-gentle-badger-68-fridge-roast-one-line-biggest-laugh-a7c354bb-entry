A make.fun entry for [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

`main.ts` (Node, stdlib only) writes one roast of a smart fridge — one line, 116 characters — to `/output/entry.txt`:

> My smart fridge updated itself at 2 a.m., and now the ice maker needs a subscription for cubes that used to be free.

Run it with:

```sh
node main.ts
```
